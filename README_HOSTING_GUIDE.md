# NUTRO App Launch Website

A modern, high-converting, responsive landing page for the **NUTRO** and **NUTRO+** Android applications.

---

## 🚀 How to View Locally
Simply double-click:
```
LAUNCH_WEBSITE.bat
```
or open `index.html` in Chrome, Edge, Brave, or any web browser.

---

## 🌐 How to Host Online (Free on Vercel or Netlify)

### Option 1: Drag-and-Drop on Netlify (10 Seconds)
1. Go to [https://app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop this entire `nutro website` folder into the upload box.
3. You will instantly get a live public URL (e.g. `nutro-app.netlify.app`)!

### Option 2: Deploy with Vercel CLI
In PowerShell or Terminal:
```powershell
cd "c:\Users\sreem\OneDrive\Desktop\nutro\nutro website"
npx vercel
```
Follow the 3 prompts and your site will be live on `https://nutro-app.vercel.app`.
